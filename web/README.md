# Frontend · Canasta Básica Alimentaria

Aplicación Next.js 16 + shadcn/ui del simulador de la CBA. Consume
`src/data/basket.json`, generado por el pipeline de `../pipeline`.

```bash
pnpm install
pnpm dev
```

La documentación completa (problema, arquitectura, datos, licencias, uso de IA y
limitaciones) está en el [README principal](../README.md).
